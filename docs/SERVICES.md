# 定制开发（商业化展示位）

> 开源承诺不变：核心功能永久开源（MIT）。本页只陈列**围绕开源版的对接与定制服务**——属于「你的场景与 ConFlow 之间的胶水」，不是把核心功能锁进付费墙。

## 服务包

### 1. 私有视频源接入
企业内网视频平台 / 自建点播系统 / 带版权保护的信源，yt-dlp 覆盖不到或需要凭据网关。
**交付物**：`engine/` 视频源适配器 + 凭据管理方案 + 部署验收。参考基线：插件规范 v1 的视频源接口（v2 候选，定制项目可提前实现）。

### 2. 企业内容库对接
发布目标不是 WordPress / 静态站，而是自建 CMS、DAM、知识库或审批流。
**交付物**：`server/pushers.py` 适配器（或经 Webhook 对接 n8n/Make 流水线）+ 字段映射 + 幂等策略 + 审批链路联调。

### 3. 专属文体与主题
团队有固定的稿件范式（白皮书体 / 合规审校体 / 品牌 VI 主题）。
**交付物**：`prompts/doc-<你的文体>.md` 方法论资产（含防幻觉规则裁剪）+ `themes.css` 品牌主题 + 样稿两轮打磨。

## 工作方式

1. 开 Issue 或联系维护方描述场景 → 2. 评估是否其实一个插件就能解决（优先指导你自己做，开源版足够）→ 3. 确需定制的报价与排期 → 4. 交付物含文档与验收脚本，代码按 MIT 回馈社区（除非涉及你的私有系统凭据）。
