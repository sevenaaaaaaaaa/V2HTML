# ConFlow 使用指南

> 核心定位 · Features · 具体用例。写给刚开始用 ConFlow 的技术团队、内容创作者与
> 想把视频变成文档的人,也是官网素材源之一。

---

## 核心定位

看视频学东西很慢:视频没法搜索、没法引用、没法分享;手工把一小时视频整理成文章和 PPT,往往要花三小时。ConFlow 把这件事变成一条命令——**提交一条 YouTube 链接,拿回可直接上线的文章和重新设计的幻灯片**。

它不是字幕流水账。确定性工作(抓取、字幕、抽帧)交给脚本,语义工作(文体判定、结构重组、写作、幻灯片设计)交给 LLM;数字逐字核对、补全显式标注、作者立场与写作者立场分离,这些防幻觉规则写在 `prompts/` 里,客户端与服务端共用同一套方法论。

反方向同样成立:`v2video` 把文章或幻灯片逆向成分镜提示词包(Sora / Veo / 可灵可直接用)。视频和文档从此双向互通。ConFlow 是芭乐派矩阵 Studio 层的本地工具,可完全独立使用,也可一键把产出推进 OpenFlow 内容库。

## Features(按你将真实用到的顺序)

### 1. 提交:一句话或一个网页
装好客户端技能后,在 ZCode 里说「用 v2html 把这条视频转成教程和幻灯片:<url>」;或者自建服务端,打开 `http://localhost:8400` 粘贴链接提交,任务队列自动跑。**频道 / 播放列表链接也直接支持**——自动展开为任务队列,已做过的自动跳过;长期供给可在后台「订阅」里设检查周期。

### 2. 四文体自动判定
教程 / 科普 / 评论 / 评测访谈,各有专属写作法(`prompts/doc-*.md`),规则驱动自动判定,也可以手工指定 `doc_type`:

| 视频类型 | 产出写法 |
|---|---|
| 教程类 | 可复现的教程文档:命令逐字核对 + 避坑清单 |
| 科普类 | 分层递进:直觉 → 机制 → 边界 + FAQ |
| 口播评论 | 论点拆解 + 论据可信度分级(✅⚠️❌) |
| 评测 / 访谈 | 评分卡前置的评测纪要 / 议题分组纪要 |

### 3. 同一次分析,按需多产出
`doc.md`(按论证结构重写的文章)+ `slides.html`(30 主题重构型幻灯片,非截图拼贴)默认双产出;勾选后追加 **45–90s 短视频口播脚本**(`script.md`,节拍表与分镜接口同构)与**分镜物料包**(`storyboard/`,含 storyboard.json 渲染接口、旁白、字幕),产出语言可选中文 / English / 日本語等十种。

### 4. 幻灯片放映:浏览器就是放映厅
单文件零依赖,仅嵌入含独有信息的原视频帧,每页标注时间戳,讲错了随时回跳原视频核对。`→` 翻页、`O` 总览、`F` 全屏、`P` 导出 PDF、`T` 实时换主题——放映前先选个顺眼的。

### 5. 逆向 v2video:文章变视频物料
把一篇文章或一组幻灯片变成分镜提示词包(Sora / Veo / 可灵),或输出 HTML 动画演示,存量内容有了第二分发形态。

### 6. 管理后台与 HTTP API
`/admin` 进后台:仪表盘、任务重试 / 推送 / 删除、执行日志与文档预览、LLM 在线热配置;公网部署设 `CONFLOW_TOKEN`(旧 `V2HTML_TOKEN` 仍兼容),`POST /api/jobs` 等接口全程可用。

### 7. 多目标推送:内容供给端
任务完成后自动把文章送达配置的目标(后台「系统配置 → 推送到内容库」可选):**OpenFlow** 内容库(幂等覆盖、写前备份,后台一键发布)、**WordPress**(REST + 应用密码)、**静态目录**(自包含 HTML,任意静态站直接挂)、**Webhook**(POST JSON 给 n8n / Make / 自建流水线)。默认草稿态——视频 → 文章 → 站点,一条链路。

## 具体用例(可直接照抄的实战路径)

### 用例 A · 把看过的视频沉淀为团队文档(技术团队 / 自学者)
1. `git clone` 仓库,`pip3 install yt-dlp`,跑 `bash bin/install-skills.sh` 注册技能;
2. 在 ZCode 里说:「用 v2html 把这条视频转成教程和幻灯片:<url>」;
3. 打开产出的 `doc.md`,核对「避坑清单」一节,补上你们团队的环境差异;
4. 幻灯片按 `P` 导出 PDF,丢进新人入职材料。
**结果**:一小时的视频,二十分钟变成可搜索、可引用、可复现的团队文档。

### 用例 B · 存量文章变视频物料(内容创作者)
1. 在 ZCode 里说:「用 v2video 把这篇文章变成分镜提示词包」;
2. 拿到适配 Sora / Veo / 可灵的分镜提示词,逐镜检查画面描述;
3. 想覆盖不支持视频的渠道?让 v2video 改出 HTML 动画演示,同样可用;
4. 生成视频后按平台裁剪分发。
**结果**:一篇旧文章多了一条视频分发渠道,不用从零写脚本。

### 用例 C · 服务端批量处理 + 直进 OpenFlow 草稿箱(内容运营)
1. 按快速上手起服务端:`.env` 填 `CONFLOW_LLM_API_KEY`(旧 `V2HTML_LLM_API_KEY` 仍兼容,任何 OpenAI 兼容接口),`bash server/run.sh`;
2. 打开 `http://localhost:8400` 依次提交本周要消化的视频链接;
3. `/admin` 看进度,失败的点重试;
4. 满意的文章点「推送」,进 OpenFlow 内容库草稿态,审完一键发布。
**结果**:视频消化变成流水线,产出直接供给站点内容库,不再手动搬运。

### 用例 D · 换主题、导出 PDF:给汇报挑一套皮(讲解人)
1. 拿到 `slides.html` 后,浏览器打开,按 `T` 实时切换 30 款主题,当场挑;
2. 按 `O` 进总览,检查页面结构与信息密度,删掉重复页;
3. 定稿后按 `F` 全屏讲,或按 `P` 导出 PDF 发给没到场的人。
**结果**:同一份内容,几分钟内适配汇报、存档、外发三种场合。

## 常见问题

**没有字幕的视频能用吗?**
能。无字幕视频由内置 faster-whisper 转写兜底(CPU 可跑,首次使用需下载模型);有人工字幕的源效果仍是最佳。

**需要我自己的 LLM key 吗?**
服务端形态需要(任何 OpenAI 兼容接口);客户端形态由 ZCode 承担,不另要 key。

**客户端和服务端怎么选?**
三种形态,方法论同一套:要质量上限,用 ZCode 客户端技能,一句话驱动;要全自动与多人提交,自建服务端,浏览器排队、后台看进度;要脚本化批量跑,CLI 直转 `python3 bin/conflow.py convert <url>`,一个 OpenAI 兼容 key 即可,无需服务端。

**服务端重启后任务还在吗?**
在。任务列表已持久化(SQLite),重启不丢;重启时正在跑的任务会标记为中断,一键重试即可。

**转出来的内容能直接发布吗?**
技术上可以,但重建内容版权归原作者,发布前请确认授权。

## 进阶

- 内容产能要规模化 → 推送进 **OpenFlow** 内容库,SEO / 发布 / 分发交给它;
- 管理后台可热更新 LLM 配置,换模型不用重启;
- 想改写作法与幻灯片设计?`prompts/` 与 `templates/` 直接可读可改,客户端与服务端共用。
