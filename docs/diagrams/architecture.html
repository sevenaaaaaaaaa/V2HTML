ConFlow 工作原理：一条链接进来，两份可上线的内容出去

确定性工作交给脚本，语义工作交给 LLM——产出的不是字幕流水账，而是按论证结构重写的文章与重新设计的幻灯片。

① 输入

一条 YouTube
链接
  • 教程 · 科普 · 评论 · 评测访谈都行
  • 任何 yt-dlp 支持的源（B 站等）
→

② 确定性管线 · bin/v2h.py

脚本抓全素材
  • 代理探测 · 下载 480p 视频
  • 字幕：人工字幕优先，无字幕可本地转写兜底
  • 场景抽帧 24 张 + 关键帧联览图
→

③ 语义核心 · LLM × prompts/ 方法论

按文体方法论重写
  • 文体判定：教程 / 科普 / 评论 / 其他，各有专属写作法
  • 防幻觉规则：数字逐字核对 补全显式标注 观点归属分离
  • 幻灯片编排：跟随论证结构，不跟随时间轴
→

④ 产出（同一次分析）

📄 doc.md · 可直接上线的文章教程含命令逐字核对与避坑清单；科普分层递进；评论带论据可信度分级
🖥 slides.html · 30 主题重构型幻灯片单文件零依赖，浏览器放映 / 导出 PDF，仅嵌入含独有信息的原视频帧

两种使用形态（同一套方法论）

本机技能 or 自建服务

客户端：ZCode 技能 /v2html /v2video，一句话驱动，质量上限最高。
服务端：FastAPI + 管理后台，浏览器提交、任务队列全自动。

自动推送 · OpenFlow 内容库

任务完成即入草稿箱

文章转 HTML 写入 OpenFlow 内容库，附来源视频与配套幻灯片链接；幂等覆盖、写前备份，默认草稿态，后台一键发布。

逆向 · v2video

文章 → 视频物料

把文章 / 幻灯片逆向成分镜提示词包（Sora / Veo / 可灵直接可用）或 HTML 动画演示——内容有了第二分发形态。

ConFlow · 视频 ⇄ 内容双向引擎 —— 脚本管确定性 · LLM 管语义 · 方法论沉淀在 prompts/，客户端与服务端共用
